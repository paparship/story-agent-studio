叙事工作台使用指南

    
    
      
  1. 管理故事
    左侧每条记录（支线或主线）拥有独立的工作区文件、Agent 对话历史与长期记忆。点击「＋ 新建故事」即可开启新篇章。
    2. 
      
  2. 生成与选择题澄清
    输入故事构想后，工作流卡片会实时流式展示「理解故事 → 生成 DSL → 编译校验」。遇到关键分支或道具映射待确认时，可直接勾选推荐选项继续。
    3. 
      
  3. 源码编辑与局部修改确认
    支持在「DSL 源码」直接手改代码，也可让剧情助手局部修改。助手的修改会经过编译器实时校验并生成红绿 Diff，点击「✓ 接受修改」即可保存新版本。
    4. 
      
  4. 规划主线章节
    在章节总览中查看故事分支，点击章节编辑细节。目前支持逐章试玩，章节之间的衔接用于故事规划。
    5.
