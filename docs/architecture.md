# 项目结构

```text
故事文本 → 故事理解 → DSL 生成 → 编译与修正 → 节点图 / 试玩配置
                       ↑                        ↓
                       └──── 聊天修改与版本保存 ──┘
```

| 目录 | 职责 |
| --- | --- |
| `src/compiler` | DSL 解析、编译、诊断、目标协议校验 |
| `src/workflow` | 故事理解、生成、修正、问答与修改流程 |
| `src/llm` | OpenAI 兼容的流式模型客户端 |
| `src/storage` | IndexedDB 故事、草稿、提案、版本存储 |
| `src/data` | 工作流使用的资源与协议数据 |
| `public/ui` | 工作台布局、剧情图、源码视图与设置 |
| `public/showcase` | 项目展示页、视频与字幕 |
| `proxy` | 默认模型服务代理与额度管理 |
| `tests` | 编译器、工作流及浏览器核心模块测试 |
| `scripts` | 资源导入与部署检查工具 |

工作台将源剧本、编译产物和保存版本分开管理。修改先产生提案，经编译后交给作者确认，再更新已保存版本。普通问答只返回解释。

独立支线围绕一份故事展开；主线以章节总览组织多份章节剧本，单章复用同一套编辑与试玩流程。
